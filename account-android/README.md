# Shared Android account

`MatrixAccount(Context)` owns the host's encrypted Passport session. Network methods are blocking and require a worker thread. `passportSession()` returns `null` when signed out, otherwise a detached projection of `uid`, `x_tt_token`, `cookies` and `email`. A valid local session has a UID and a token or cookies; server acceptance is checked when authorizing. A legacy host maps its `token` field to `x_tt_token` before calling `importPassportSession`, and removes its legacy copy only after successful import.

`grantFor(appId, installedPackage)` reads the installed APK's `assets/matrix-embedded.json`, checks its app/package identity, and obtains a fresh real application grant using the installed signer's public-key hash. The config requires `schema: 1`, `appId`, `package`, and `account.agwKey` for the pinned vendor protocol. Passport state stays in host storage; target refresh tokens are never cached there.

Call `GrantProvisioner.provision(context, appId, packageName, expectedSignerSha256)` after successful installation. The expected digest is SHA-256 of the actual target signing certificate, as returned by preparation/signing. It is distinct from the host certificate pinned by the target provider. The provisioner verifies the target receiver before authorization, launches the target, and uses its one-use `begin`/`provision` challenge. Its overload with `launchTarget=false` supports an already running receiver. Missing account, receiver or network authorization throws; the host should retain the installed application and allow its in-app login. Package visibility declarations belong to the host integration.

The embedded runtime uses `TargetIdentity.embedded(context)` and the shared `AccountClient`. Only the standalone research companion has an explicit VD fixture. Embedded login and imported grants store only the target grant and user. The target refreshes independently; host logout prevents subsequent host handoff without erasing target sessions.

Storage remains byte-compatible with the earlier runtime: `noBackupFilesDir/account.sealed`, Keystore alias `org.picomatrix.bridge.account.v1`, version byte 1, 12-byte AES-GCM IV and ciphertext/tag. Atomic writes and generation checks reject in-flight or queued account work after logout/replacement. Existing encrypted state does not need a device migration. Instrumented encrypted storage coverage and local tests for projections, identity, expiry and generation invalidation are included.
